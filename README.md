# sha256_demo

A minimal Rust program that computes the SHA-256 hash of a file and prints it to the terminal. Functionally equivalent to the Python `hashlib` one-liner, but compiles to a single self-contained binary with no runtime dependencies.

---

## Project structure

```
sha256_demo/
├── Cargo.toml      ← dependency manifest (the Rust equivalent of requirements.txt)
├── Cargo.lock      ← auto-generated, pins exact crate versions (commit this to git)
├── README.md       ← this file
└── src/
    └── main.rs     ← all application code (8 lines)
```

### What each file does

| File | Purpose |
|------|---------|
| `Cargo.toml` | Declares the package name, Rust edition, and two external crates: `sha2` (the hashing algorithm) and `hex` (converts raw bytes to a printable hex string). You edit this by hand. |
| `Cargo.lock` | Auto-generated by `cargo`. Records the exact version of every dependency and sub-dependency so builds are reproducible. Never edit manually. |
| `src/main.rs` | The program. Reads the file into memory as raw bytes, feeds it to `Sha256::digest()`, encodes the result as hex, prints it. |

## Prerequisites

You need the Rust toolchain installed. The standard way is via `rustup`, which manages Rust versions and the `cargo` build tool.

### Install Rust (one-time)

**macOS / Linux:**
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
Then restart your terminal, or run:
```bash
source "$HOME/.cargo/env"
```

**Windows:**  
Download and run the installer from https://rustup.rs — it installs both the compiler (`rustc`) and the build tool (`cargo`).

Verify the installation worked:
```bash
rustc --version
cargo --version
```
You should see version numbers for both. Anything from Rust 1.65+ works fine for this project.

## Build

Navigate into the project folder:
```bash
cd sha256_demo
```

Build in **debug mode** (fast to compile, slower binary — good for development):
```bash
cargo build
```
The binary is placed at `target/debug/sha256_demo`.

Build in **release mode** (optimised binary — use this for any real workload):
```bash
cargo build --release
```
The binary is placed at `target/release/sha256_demo`.

> The first build downloads and compiles the `sha2` and `hex` crates from crates.io. This takes 10–30 seconds. Subsequent builds are incremental and near-instant.

## Run

### Method 1 — `cargo run` (builds and runs in one step)

Hash the default file (`mysequence.txt` must exist in the directory you run from):
```bash
cargo run
```

Hash a specific file:
```bash
cargo run -- mysequence.txt
cargo run -- /path/to/any/file.txt
```

With release optimisations:
```bash
cargo run --release -- mysequence.txt
```

### Method 2 — run the compiled binary directly

After `cargo build --release`:
```bash
./target/release/sha256_demo mysequence.txt
```

On Windows:
```powershell
.\target\release\sha256_demo.exe mysequence.txt
```

### Expected output

```

e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
```
(The hash above is the SHA-256 of an empty file — your actual hash will differ.)

## How the code works

```rust
use sha2::{Sha256, Digest};   // import the SHA-256 hasher and the Digest trait
use std::fs;                  // standard library file I/O
use std::env;                 // standard library for reading command-line arguments

fn main() {
    // Read first CLI argument, fall back to "mysequence.txt" if none given
    let filename = env::args().nth(1).unwrap_or_else(|| "mysequence.txt".to_string());

    // Read entire file as raw bytes; exit with a clear error message if it fails
    let data = fs::read(&filename).unwrap_or_else(|e| {
        eprintln!("Error reading '{}': {}", filename, e);
        std::process::exit(1);
    });

    // Compute the hash and encode as lowercase hex string
    let hash = hex::encode(Sha256::digest(&data));

    println!("SHA-256 hash of '{}':\n{}", filename, hash);
}
```

Key points:
- `fs::read()` returns `Vec<u8>` — a heap-allocated byte array. Rust owns this memory and frees it automatically when `data` goes out of scope at the end of `main`. No garbage collector involved.
- `Sha256::digest(&data)` takes a reference (`&`) to the data — it borrows the bytes without copying them. This is the borrow checker at work: zero extra allocation.
- `unwrap_or_else` is idiomatic Rust error handling — instead of exceptions, the `Result` type forces you to decide what to do when something goes wrong.

## Dependencies explained

```toml
[dependencies]
sha2 = "0.10"    # SHA-2 family of hash functions (SHA-256, SHA-512, etc.)
hex  = "0.4"     # encodes &[u8] byte slices as "aabbcc..." hex strings
```

Both are from the [RustCrypto](https://github.com/RustCrypto) project — the de facto standard cryptography crates in the Rust ecosystem. The `"0.10"` notation means "any compatible version ≥ 0.10.0, < 0.11.0". `cargo` resolves and pins the exact version in `Cargo.lock`.

## Verify against system tools

You can cross-check the output against your OS hash utility:

**macOS:**
```bash
shasum -a 256 mysequence.txt
```

**Linux:**
```bash
sha256sum mysequence.txt
```

**Windows (PowerShell):**
```powershell
Get-FileHash mysequence.txt -Algorithm SHA256
```

The hex string should be identical.
